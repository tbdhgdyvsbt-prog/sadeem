# سديم (Sadeem) 🌌
## A Galactic P2P Messenger

Sadeem is a decentralized, peer-to-peer messaging application designed to work without an internet connection. It leverages local network protocols to allow users to send messages and files in an environment that feels like exploring the cosmos.

### 🚀 Core Features
- **Internet-Free Communication:** Works via LAN/Wi-Fi Direct.
- **P2P Architecture:** No central server; direct device-to-device connection.
- **Space-Themed UI:** A futuristic, immersive interface inspired by nebulae and deep space.
- **File Sharing:** Seamless transfer of documents and media.

### 🛠️ Tech Stack (Proposed)
- **Framework:** Flutter (for a stunning, cross-platform UI).
- **Language:** Dart.
- **Protocols:** UDP Broadcasting/mDNS for discovery, TCP Sockets for data transfer.
